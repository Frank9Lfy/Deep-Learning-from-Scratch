## 说明
1. 此项目中所有笔记**均为原创**，请转载时说明来源出处
2. 各个笔记及代码含有作者自己的理解，并非对书中代码的之间复现。也包含了额外的补充（DeepSeek的chat链接），用于加深理解
3. 目录结构文件按照书本章节顺序，每一模块的代码文件之间知识联系紧密，模块环环相扣。不建议Python零基础的用户阅读。
4. 由于本人对于深度学习，还在入门阶段，笔记代码中有些理解不到位或者错误的地方，欢迎发起issue指正，也欢迎大家在讨论区交流读书、学习心得
